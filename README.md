# DiagnoSee — React / Next.js source

Complete Next.js App Router application, converted from the PPT-aligned 13-page release. All website routes are editable JSX. There is no Python dependency, HTML-injection wrapper, iframe, or legacy script application.

## Requirements and commands

Node.js 20.9+ (Node 22 or 24 recommended) and npm.

```sh
npm ci
npm run dev
```

Open http://localhost:3000. To build, test and preview the export:

```sh
npm test
npm run build
npm start
```

`npm start` serves the static build locally. Set `PORT` to use a different port. Do not use `next start` for this export configuration.

## Project map

- `app/`: 13 real App Router pages, shared layout, metadata and custom 404.
- `components/`: React header/mobile navigation, footer, product tabs, scroll walkthrough, six-stage workflow explorer, dashboard, image/briefing dialogs and form.
- `data/`: platform content and deterministic synthetic dashboard records.
- `styles/`: original medical design styles in their original cascade order.
- `public/assets/`: all supplied presentation artwork and website image assets.
- `docs/`: slide text, presentation alignment audit, image prompts and migration notes.
- `tests/`: tests for sample counts and combined dashboard filters.
- `scripts/preview.mjs`: local static preview server.
- `package-lock.json`: reproducible dependency versions.

Edit content directly in `app/**/page.jsx` and `data/platform.json`. Edit shared sections in `components/`. Do not edit `.next/` or `out/`; both are generated by Next.js. All images are included locally; the preserved design uses Google Fonts through a CSS import, with system-font fallbacks.

## Hosting and your own domain

The project uses Next.js `output: 'export'`. `npm run build` creates `out/`, which any static hosting provider can serve. Upload the **contents** of `out/` to your web root, preserving subdirectories and `_next/`. The source ZIP deliberately excludes generated output and dependencies; `npm ci` plus `npm run build` recreates them.

For a Git-connected host, install with `npm ci`, build with `npm run build`, and choose `out` as the publish directory. Configure your domain, DNS and HTTPS with that provider. No ChatGPT account or API is needed to run this project independently. The current hosted preview retains its existing address; a custom domain or another hosting account is needed for a different address.

Static export reference: https://nextjs.org/docs/app/guides/static-exports

## Scope retained

- Original PPT tagline, content, care stages, clinical details and graphics.
- React-controlled tabs, dashboard views, programme/district/facility/date filters, pagination, CSV exports and briefing download.
- Responsive menu, reading progress, reduced-motion support and native accessible dialogs.
- Dashboard records and clinical screens are illustrative, not actual patient data.
- Request Demo prepares a local downloadable brief; it does not send an enquiry. Add a real submission service if required.
- No clinical login service or RIS/PACS backend is included. The presentation did not supply those endpoints.

Plain anchors are used for full page navigation, while all in-page interactions use React. This keeps the existing navigation behavior and resets page-specific scroll state on each route.
