# React / Next.js migration

The existing 13-route presentation-aligned website has been converted into native JSX route files and reusable React components. Python generators and legacy DOM-rendering scripts are removed. Content and assets are retained from source commit 0e2e4c1d6046f6359ac03914cbef71745a9cabe9.

Stateful features now use React state: preview tabs, workflow tabs, scroll-stage selection, dashboard views/filters/pagination, mobile navigation, image dialog selection and briefing success state. Effects clean up event listeners and intersection observers on unmount. Native dialog triggers are delegated so server-rendered calls to action can open the shared client dialog.

The complete source is independent of the managed live hosting. The production static export is generated by Next.js, not the former Python build. Existing source presentation conflicts and backend exclusions remain documented in CONTENT-COVERAGE.md.

Validation: successful Next.js production build; content parity and local-link checks; Node tests for dashboard counts, composable filters and date boundaries. Browser visual QA was not performed for this migration.
